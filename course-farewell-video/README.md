# course-farewell-video — 班级结课煽情视频插件

> 给 ZCode 装上这个插件，丢给模型一组课堂素材 + 一首 BGM，就能自动产出约 83 秒的结课煽情成片：
> **AI 插画序章 → 递推开场 → 课件快剪 → 学生留言催泪幕 → 老师寄语 → DP 尾声 → 落款卡 → 下期预告卡**
> 已在 ZCode + GLM 实际交付：猿编程 A3 班《数据结构与高级算法》结课视频。

---

## 一、安装（一次性，2 分钟）

1. 下载本仓库（Code → Download ZIP，解压备用）
2. ZCode → **设置 → 插件管理 → 发现 → ＋**，添加方式选 **本地目录**，指向解压后的仓库文件夹
3. 在插件列表中找到 **course-farewell-video** → 安装 → 启用
4. **新开一个会话**（重要，老会话看不到新插件），输入 `/` 能看到 `course-farewell-video` 即安装成功

> 也可以手动方式：把 `skills/course-farewell-video` 整个文件夹拷到 `~/.agents/skills/` 下，效果相同。

## 二、环境依赖（机器一次性配置）

模型（GLM）会自动检查这些，缺什么它会提示你怎么装。想提前配好可对照：

| 依赖 | 检查命令 | 安装 |
|------|---------|------|
| ffmpeg | `ffmpeg -version` | `brew install ffmpeg` |
| Python3 + Pillow | `python3 -c "import PIL"` | `pip3 install pillow` |
| 中文字体 | macOS 自带苹方即可 | 其他系统需一个中文 ttf/ttc |

## 三、使用（每次只需 3 步）

### 第 1 步：准备素材

把素材放进一个文件夹。素材内容和数量可以不同，模型会自动盘点识别；如果想完全复刻默认结构，按下表准备：

| 素材 | 数量 | 用途 |
|------|------|------|
| 老师出镜口播 | 4 段 | 第四幕寄语（自动保留原声） |
| 课件/直播录屏 | 2 段 | 第二幕知识回顾快剪 |
| 学生评价留言滚动录屏 | 1 段 | 第三幕催泪点（自动摘取真实留言+时间戳） |
| 一张 2×2 AI 插画（可选） | 1 张 | 序章「按下回车照亮屏幕」背景 |
| 一张课件截图（可选） | 1 张 | 第一幕递推背景 |
| BGM 一首 mp3 | 1 首 | 如《起风了》《那些年》 |

### 第 2 步：对模型说一句话

```
帮我用 ~/Desktop/素材 文件夹里的素材做一个结课视频，BGM 用 ~/Desktop/起风了.mp3
```

模型会自动触发 skill：先盘点素材 → 产出脚本文档（分镜+字幕文案）**给你确认**。

> ⚠️ 确认脚本时重点看两处：① 老师出镜段的字幕文案是模型代写的，建议对照原话修正；② 第三幕留言应摘自你班级的真实评价内容。

### 第 3 步：确认后自动合成

回复确认，模型自动完成切片、字幕、动效、配乐混音、拼接，输出：

```
<输出目录>/结课视频_成片.mp4     （1920×1080，约 83 秒）
```

抽帧自检通过后交付；中间产物保留在 `build/` 子目录，想改某一段随时说。

## 四、常用调整（对模型说就行）

| 需求 | 说法示例 |
|------|---------|
| 换画幅 | 「改成 4:3」/「竖版 9:16」 |
| 换文案 | 「第三幕留言换成 XXX」「老师那段字幕改成……」 |
| 换 BGM | 「BGM 换成《那些年》」 |
| 改时长 | 「压到 1 分钟内」「结尾再加一帧 XXX」 |
| 删卡顿 | 「41 秒那里卡顿，删掉」 |
